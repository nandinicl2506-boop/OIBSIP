# Python Task 2: BMI Calculator 

## Overview
A clean, robust command-line Python application that calculates a user's Body Mass Index (BMI) based on weight and height inputs, classifies the result into standard health categories, and handles input validation gracefully.

## Features
   > Accurate Calculation: Uses the standard formula: Weight/Height**2
   > Intelligent Validation: Rejects negative numbers, zero, and non-numeric inputs without crashing
   > User-Friendly UX: Includes built-in helpful guidance (such as reminding and guiding users to convert centimeters to meters if needed)
   > Clear Categorization: instantly outputs whether the user is Underweight, Normal weight, Overweight, or Obese

## Tech Stack
Language: Python 3 (Using modular functions, math libraries, and type hints)
